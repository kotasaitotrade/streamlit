# Windows での 30分ごと自動実行

**Windows のタスクスケジューラで、30分ごとに sedori-tool を自動実行します。**

⏱️ **所要時間: 約 10 分**

---

## 📋 このページで行うこと

1. ✅ タスクスケジューラを開く
2. ✅ 新規タスクを作成
3. ✅ スケジュールを設定（30分ごと）
4. ✅ 実行プログラムを指定
5. ✅ 動作確認

---

## ステップ 1: タスクスケジューラを開く

### 1-1. ファイル名を指定して実行

**Windows キー + R** を同時押し：

```

│ ファイル名を指定して実行              │

│ ┌──────────────────────────────────┐│
│ │ 名前(N):                          ││
│ │ ┌────────────────────────────┐   ││
│ │ │ taskschd.msc               │   ││

│ │                                  ││
│ │ ▶ [OK]      [キャンセル]          ││
│ └──────────────────────────────────┘│
│                                      │
└──────────────────────────────────────┘
```

**「OK」をクリック** → タスクスケジューラが起動

## ステップ 2: 新規タスクを作成

### 2-1. 「タスクの作成」をクリック

タスクスケジューラが開いたら、右側のアクションパネルから **「タスクの作成」** をクリック：

```

│  今ここ                                │
│                                        │

│ └────────────────────────────────────┘│
│                                        │
│ 説明(D):                               │
│ ┌────────────────────────────────────┐│
│ │ 30分ごとにメルカリ値下げを実行      ││
│ └────────────────────────────────────┘│
│                                        │

│ ☑️ この使用者がログインしているとき   │
```

## ✅ 動作確認

タスクが正常に実行されているか確認する方法：

### 方法 1: ログファイルで確認

タスク実行時に以下のロ。グが記録されます：

```
C:\Users\(ユーザー名)\Desktop\sedori-tool\log\
```

ファイルを開いて、実行ログを確認

### 方法 2: タスク履歴を確認

タスクスケジューラで、sedori-tool-autoschedule を選択し、  
**「履歴」** タブで実行状況を確認：

```
タスク: sedori-tool-autoschedule
状態: 成功
最後に実行: 2026-06-06 09:00:00
```

### 方法 3: Discord 通知を確認

設定した Discord チャンネルで、値下げ通知が届いているか確認：

```
📉 メルカリ値下げ完了

iPhone SE 第3世代
定価: ¥9,999 → 新価格: ¥9,499
-¥500 値下げ

実行時刻: 2026-06-06 09:00:15
```

## ❌ タスクが実行されない場合

### エラー 1: タスクが登録されていない

**対応方法:**
1. タスクスケジューラを再度開く
2. 左のツリーから「タスク スケジューラー ライブラリ」を展開
3. **sedori-tool-autoschedule** が表示されているか確認

### エラー 2: プログラムのパスが間違っている

**エラー表示:**
```
指定されたパスが見つかりません
```

**対応方法:**
1. エクスプローラーで実際のパスを確認
2. タスクスケジューラで該当タスクを編集
3. 「操作」タブで正しいパスを再度設定

**正しい例:**
```
C:\Users\yamada\Desktop\sedori-tool\4_メルカリ値下げ.bat
```

### エラー 3: セキュリティソフトがブロック

Windows Defender がバッチファイルの実行をブロック：

**対応方法:**
1. Windows セキュリティを開く
2. 「ウイルスと脅威の防止」をクリック
3. 「除外の管理」で以下を追加：
   ```
   C:\Users\(ユーザー名)\Desktop\sedori-tool\
   ```

### エラー 4: タスクスケジューラのエラー

ログに以下のエラーが出ている場合：

```
Error: タスク実行エラー
Code: 0x41300 or 0x80070005
```

**対応方法:**
1. タスクスケジューラを管理者として実行
2. タスクを削除して再度作成

```
cmd.exe を管理者として実行して：
sc stop schedule
sc start schedule
```

### 朝 9 時から夜 23 時まで実行

```
開始時刻: 09:00:00
繰り返し間隔: 30 分

実行時間:
09:00 → 09:30 → 10:00 → ... → 23:00 → 23:30

（自動的に夜 24 時で停止）
```

### 24 時間 365 日実行

```
開始時刻: 00:00:00
繰り返し間隔: 30 分
期間: 無制限

実行時間:
00:00 → 00:30 → 01:00 → ... → 毎日継続
```
