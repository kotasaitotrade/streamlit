# ライセンス認証

**セットアップが完了したら、ライセンスキーで認証します。**

⏱️ **所要時間: 約 5 分**

---

## 📋 このページで行うこと

1. ✅ メールからライセンスキーをコピー
2. ✅ 設定画面でライセンスキーを入力
3. ✅ ライセンス認証を実行
4. ✅ 認証完了を確認

---

## ステップ 1: ライセンスキーをメールで受け取る

### 1-1. メールを確認

ライセンスキーが送信されたメールを開いてください。

**メール内容の例:**

```
┌────────────────────────────────────────┐
│ From: noreply@sedori-tool.com          │
│ To: your-email@example.com             │
│ Subject: ライセンスキーが発行されました │
├────────────────────────────────────────┤
│                                        │
│ いつもお利用いただきありがとうございます  │
│                                        │
│ ライセンスキーが発行されました。        │
│ 以下のキーを「設定画面」に入力してください│
│                                        │
│ 📋 ライセンスキー:                      │
│ ┌────────────────────────────────────┐│
│ │ SEDORI-XXXX-YYYY-ZZZZ              ││
│ │ （テキストをコピーして使用してください）││
│ └────────────────────────────────────┘│
│                                        │
│ ▶ ライセンス認証ガイド                 │
│ ▶ トラブルシューティング               │
│                                        │
│ ©2026 sedori-tool                     │
└────────────────────────────────────────┘
```

### 1-2. ライセンスキーをコピー

ライセンスキー（例: `SEDORI-XXXX-YYYY-ZZZZ`）の部分を選択して、**コピー（Ctrl+C または Cmd+C）** します。

> **⚠️ 重要**: キーをコピーするときは、前後に空白がないか確認してください。

---

## ステップ 2: 設定画面を開く

### 2-1. Windows の場合

デスクトップの **sedori-tool** フォルダを開き、  
**1_設定画面を開く.bat** をダブルクリック：

**フォルダ内容:**

```
📁 sedori-tool/
├─ 0_初回セットアップ.bat
├─ 1_設定画面を開く.bat    ← ダブルクリック
├─ 2_メルカリ新着.bat
└─ ...
```

### 2-2. Mac の場合

Finder で **Desktop** → **sedori-tool-mac** を開き、  
**1_設定画面を開く.sh** をダブルクリック：

**フォルダ内容:**

```
📁 sedori-tool-mac/
├─ 0_初回セットアップ.sh
├─ 1_設定画面を開く.sh    ← ダブルクリック
├─ 2_メルカリ新着.sh
└─ ...
```

## ステップ 3: ライセンスキーを入力

### 3-1. 入力欄をクリック

「ライセンスキーを貼り付け」の入力欄をクリック：

```
┌──────────────────────────────────────┐
│ ライセンスキーを入力                  │
│ ┌────────────────────────────────┐   │
│ │ ここをクリック ← マウスカーソル  │   │
│ └────────────────────────────────┘   │
│                                      │
└──────────────────────────────────────┘
```

### 3-2. ライセンスキーを貼り付け

**Ctrl+V（Windows）** または **Cmd+V（Mac）** でペースト：

```
┌──────────────────────────────────────┐
│ ライセンスキーを入力                  │
│ ┌────────────────────────────────┐   │
│ │ SEDORI-XXXX-YYYY-ZZZZ    ✅    │   │
│ └────────────────────────────────┘   │
│                                      │
│ ✅ ライセンスキーが有効です           │
│                                      │
└──────────────────────────────────────┘
```

### 3-3. 認証を実行

**「認証を実行」** ボタンをクリック：

```
┌──────────────────────────────────────┐
│ ライセンスキーを入力                  │
│ ┌────────────────────────────────┐   │
│ │ SEDORI-XXXX-YYYY-ZZZZ          │   │
│ └────────────────────────────────┘   │
│                                      │
│      ⏳ 認証中...                    │
│      [認証を実行]                    │
│                                      │
└──────────────────────────────────────┘
```

> ⏳ **認証処理中（数秒待ってください）**

**Windows の場合:**

```

```

**Mac の場合:**

```

```

## ❌ 認証に失敗した場合

### エラー 1: 「ライセンスキーが無効です」

**エラー表示:**

```
┌──────────────────────────────────────┐
│ ❌ 認証に失敗しました                 │
│                                      │
│ エラー: ライセンスキーが無効です       │
│                                      │
│ 原因:                                │
│ 1. キーが間違っている                │
│ 2. キーの前後に空白がある            │
│ 3. ネットワーク接続エラー            │
│                                      │
│ 対応方法:                            │
│ 1. メールを開き直す                 │
│ 2. キーをもう一度コピーする          │
│ 3. 前後の空白を削除する              │
│ 4. 再度「認証を実行」をクリック      │
│                                      │
│        [再度実行]                     │
│                                      │
└──────────────────────────────────────┘
```

**対応方法:**

1. メールを開き直す
2. ライセンスキーをもう一度選択してコピー
3. 入力欄に貼り付ける
4. **「認証を実行」** をもう一度クリック

### エラー 2: 「ネットワーク接続エラー」

**エラー表示:**

```
❌ 認証に失敗しました

エラー: ネットワーク接続エラー
インターネット接続を確認してください。
```

**対応方法:**

1. インターネット接続を確認
2. WiFi を再接続
3. **「認証を実行」** をもう一度クリック

### エラー 3: 「ライセンスキーが有効期限切れです」

**エラー表示:**

```
❌ 認証に失敗しました

エラー: ライセンスキーが有効期限切れです
ライセンスを更新してください。
```

**対応方法:**

ライセンスを更新してください。  
👉 **[ライセンス更新ページ](https://sedori-tool.com/license)**
