# Mac での初回セットアップ

このページでは、Mac でせどりツールをセットアップする手順を **完全にガイド** します。  
**スクリーンショット付き** で、初心者でも安心して進められます。

⏱️ **所要時間: 約 15 分**

---

## 📋 このページで行うこと

1. ✅ ダウンロード（Google Drive から）
2. ✅ 展開（解凍）
3. ✅ セキュリティ署名の修正
4. ✅ 初回セットアップの実行
5. ✅ セットアップ完了の確認

## ステップ 1: ダウンロード

### 1-1. ダウンロード用 URL を取得

以下の手順で sedori-tool のダウンロード URL を取得してください：

**方法 1: メールから取得（推奨）**

購入完了メールに、ダウンロード用 URL が記載されています。

```
【重要】sedori-tool ダウンロード URL
────────────────────────────────────

ご購入いただきありがとうございます。

以下の URL にアクセスして、
セットアップファイルをダウンロードしてください：

https://download.sedori-tool.com/files/sedori-tool-mac

※ この URL は個人用です。他人と共有しないでください。
```

**方法 2: ダウンロード管理画面から取得**

以下の画面から取得することもできます：

```
https://account.sedori-tool.com/downloads
（ライセンスキーでログイン）

📥 sedori-tool-mac.tar.gz
   ↓ ダウンロードボタンをクリック
```

### 1-2. ファイルをダウンロード

メールの URL、または管理画面から **sedori-tool-mac.tar.gz** をダウンロード：

```
ダウンロード完了:
~/Downloads/sedori-tool-mac.tar.gz
```

✅ ファイルが見えれば OK です。

## ステップ 2: 展開（解凍）

### 2-1. Finder で展開

Finder の **ダウンロード** フォルダで、**sedori-tool-mac.tar.gz** を **ダブルクリック**：

```
📦 sedori-tool-mac.tar.gz
         ↓ ダブルクリック
📁 sedori-tool-mac/  ← 自動的に展開される
```

**展開後:**

```
┌────────────────────────────────────────────┐
│ ファイル  編集  表示                          │
├────────────────────────────────────────────┤
│ ◀  ▶  ⬆️  📁 Downloads                   │
│ ◀────────────────────────────────────────┤
│  📁 sedori-tool-mac/  ← 展開されました    │
│  📦 sedori-tool-mac.tar.gz               │
│  (他のファイル)                           │
└────────────────────────────────────────────┘
```

### 2-2. デスクトップに移動

展開した **sedori-tool-mac** フォルダを **Desktop** に移動します。

**ドラッグ＆ドロップで移動:**

1. **sedori-tool-mac** フォルダを選択
2. **Desktop** フォルダ（左のサイドバー）にドラッグ
3. 移動完了

または、ターミナルで実行：

**ターミナル表示:**

```
┌──────────────────────────────────────────┐

│                                          │
```

✅ デスクトップに **sedori-tool-mac** フォルダが見えれば OK です。

## ステップ 3: セキュリティ署名の修正

> **⚠️ 重要**: Mac のセキュリティ機能により、ダウンロードされたアプリケーションが実行ブロックされています。  
> **この手順で解除します。**

### 3-1. ターミナルを開く

**Spotlight 検索** で「ターミナル」を検索：

1. **Command + Space** キーを同時押し
2. 検索ボックスに「**ターミナル**」と入力

**Spotlight 検索画面:**

```
┌────────────────────────────────────┐
│ 🔍                                 │
│  ターミナル                         │
│  ┌──────────────────────────────┐ │
│  │ ターミナル.app               │ │
│  └──────────────────────────────┘ │
│  マップ                             │
│  プレビュー                         │
│  (他のアプリ)                      │
└────────────────────────────────────┘
```

**ターミナルをクリック** → ターミナルが開きます。

### 3-2. セキュリティ解除コマンドを実行

ターミナルを開いた後、以下のコマンドをコピー＆ペーストして **Enter** を押します：

```bash
cd ~/Desktop/sedori-tool-mac
xattr -rd com.apple.quarantine bin/monitor bin/pricedown
```

**ターミナル画面:**

```
┌──────────────────────────────────────────┐
│ Terminal (zsh)                            │
├──────────────────────────────────────────┤
│                                          │
│ user@MacBook ~ % cd ~/Desktop/sedori-tool-mac
│ user@MacBook sedori-tool-mac %
│ user@MacBook sedori-tool-mac % xattr -rd com.apple.quarantine bin/monitor bin/pricedown
│                                          │
│ ✅ コマンドが正常に実行されました          │
│                                          │
│ user@MacBook sedori-tool-mac %
│
│ (カーソル点滅)█
│
└──────────────────────────────────────────┘
```

✅ **エラーなく表示されれば OK です。**

> **📌 ポイント**: このコマンドは Mac のセキュリティ機能をオフにするのではなく、  
> ダウンロード時の「隔離」属性を削除しているだけです。安全です。

## ❌ トラブルが出た場合

### エラー 1: 「コマンドが見つかりません」

**エラー画面の表示:**

```
==================================================
  sedori-tool セットアップ開始
==================================================

[error] Homebrew コマンドが見つかりません
[error] セットアップを中止しました

対応方法:
Homebrew をインストールしてください
```

**対応方法:**

1. ターミナルで以下を実行：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

2. インストール完了後、セットアップを再実行

> **⏳ Homebrew のインストールには 5〜10 分かかります。**

### エラー 2: 「Permission denied」

**エラー画面の表示:**

```
$ ./0_初回セットアップ.sh
zsh: permission denied: ./0_初回セットアップ.sh
```

**対応方法:**

ターミナルで以下を実行：

```bash
cd ~/Desktop/sedori-tool-mac
chmod +x *.sh
./0_初回セットアップ.sh
```

**ターミナル表示:**

```
┌──────────────────────────────────────────┐
│ Terminal (zsh)                            │
├──────────────────────────────────────────┤
│                                          │
│ $ cd ~/Desktop/sedori-tool-mac
│ $ chmod +x *.sh
│ $ ./0_初回セットアップ.sh
│
│ ==================================================
│   sedori-tool セットアップ開始
│ ==================================================
│
│ [info] システム環境を確認中...
│
└──────────────────────────────────────────┘
```

### エラー 3: セットアップが途中で止まった

**対応方法:**

ターミナルで再度実行：

```bash
cd ~/Desktop/sedori-tool-mac
./0_初回セットアップ.sh
```

```
==================================================
  sedori-tool セットアップ開始
==================================================

[info] 前回のセットアップから続行します
[info] 既にインストール済みのライブラリはスキップ...
...

✅ セットアップ完了！
```

### エラー 4: 「ライブラリのインストール失敗」

**エラー表示:**

```
[error] selenium のインストールに失敗しました
[error] インターネット接続を確認してください
```

**対応方法:**

1. インターネット接続を確認
2. ターミナルで再度実行

```bash
cd ~/Desktop/sedori-tool-mac
./0_初回セットアップ.sh
```

### エラー 5: 「Python が見つかりません」

**エラー表示:**

```
[error] Python 3.10 が見つかりません
[error] セットアップを中止しました
```

**対応方法:**

Homebrew で Python をインストール：

```bash
brew install python@3.10
./0_初回セットアップ.sh
```
