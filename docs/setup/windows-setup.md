# Windows での初回セットアップ

このページでは、Windows パソコンでせどりツールをセットアップする手順を **完全にガイド** します。

⏱️ **所要時間: 約 10〜15 分**（初回のみ。2回目以降はワンクリック起動）

---

## 📋 このページで行うこと

1. ✅ ZIP をダウンロードして展開
2. ✅ `setup.cmd` で初回セットアップ
3. ✅ 設定画面が開くことを確認

---

## ステップ 1: ZIP をダウンロードして展開する

### 1-1. ダウンロード管理画面を開く

購入後に届いたライセンスキーでダウンロード管理画面（ツウチマネージャー）にアクセスします。

OS のドロップダウンで **「windows」** を選択し、**「ダウンロードURLを取得」** をクリックしてください。
表示されたリンクをクリックすると **sedori-tool-win.zip** がダウンロードされます。

### 1-2. ZIP を展開する

エクスプローラーでダウンロードした ZIP ファイルを右クリック → **「すべて展開」**

```
💡 展開先は C:\sedori-tool\ など分かりやすい場所にすることをおすすめします
```

展開すると `setup.cmd`、`sedori-tool-launcher.cmd` などのファイルが入ったフォルダが作成されます。

---

## ステップ 2: 初回セットアップを実行する

### 2-1. setup.cmd をダブルクリック

展開したフォルダ内の **「setup.cmd」をダブルクリック** します。

### 2-2. SmartScreen 警告が出た場合

```
Windows によって PC が保護されました
```

この場合：

1. **「詳細情報」** をクリック
2. **「実行」** をクリック

> ℹ️ コード署名証明書がないため表示される警告です。ウイルスではありません。

### 2-3. セットアップが自動で始まる

黒い画面（コマンドプロンプト）が開き、Python・ブラウザエンジンなど必要なものを自動インストールします：

```
[1/5] Python を確認中...
[2/5] 仮想環境を作成中...
[3/5] ライブラリをインストール中...
（5〜15分かかります。画面を閉じないでください）
```

### 2-4. セットアップ完了

完了するとブラウザが自動で開きます。  
デスクトップに「sedori-tool」のショートカットが作成されます。

---

## ステップ 3: 設定画面が開くことを確認

ブラウザに以下の設定画面が表示されれば **セットアップ完了** です：

```
🛠️ せどりツール 設定画面
メルカリ・ヤフフリの新着通知と自動値下げをまとめて管理します
```

> 💡 次回以降は **デスクトップの「sedori-tool」ショートカット** をダブルクリックするだけで起動します。  
> （ショートカットがない場合はツールフォルダ内の `sedori-tool-launcher.cmd` をダブルクリック）

---

## 🎉 セットアップ完了！

**おめでとうございます！** 初回セットアップが完了しました。

次のステップに進みましょう：

## ❌ トラブルが出た場合

### setup.cmd が起動しない

**対応方法**:

1. ダウンロードした ZIP を削除してもう一度ダウンロード
2. 展開し直してから `setup.cmd` を実行

### 「アクセスが拒否されました」

**原因**: ZIP をダウンロードフォルダで展開したまま実行している

**対応方法**:

1. ツールフォルダ全体を `C:\sedori-tool\` などに移動
2. 移動後の場所から `setup.cmd` を再実行

### 設定画面が開かない

**対応方法**:

1. デスクトップの「sedori-tool」ショートカットをダブルクリック
2. または、ツールフォルダ内の `sedori-tool-launcher.cmd` をダブルクリック
3. ブラウザで `http://localhost:8501` を開く

### アンインストール・再インストール

ツールフォルダ（`C:\sedori-tool\` など展開した場所）ごと削除してください。  
再インストールは ZIP を再度ダウンロード → 展開 → `setup.cmd` を実行。

---

## 📞 それでも解決しない場合

ツールフォルダ内の `log\` フォルダにログファイルが作成されています：

```
C:\sedori-tool\log\
```
