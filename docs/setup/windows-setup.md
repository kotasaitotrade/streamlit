# Windows での初回セットアップ

このページでは、Windows パソコンでせどりツールをセットアップする手順を **完全にガイド** します。  
**スクリーンショット付き** で、初心者でも安心して進められます。

⏱️ **所要時間: 約 10 分**

---

## 📋 このページで行うこと

1. ✅ ダウンロード（Google Drive から）
2. ✅ 展開（解凍）
3. ✅ 初回セットアップの実行
4. ✅ セットアップ完了の確認

---

## ステップ 1: ダウンロード

### 1-1. ダウンロード用 URL を取得

以下の手順で sedori-tool のダウンロード URL を取得してください：

**方法 1: メールから取得（推奨）**

購入完了メールに、ダウンロード用 URL が記載されています。

```
【重要】sedori-tool ダウンロード URL
────────────────────────────────────

ご購入いただきありがとうございます。

以下の URL にアクセスして、
セットアップファイルをダウンロードしてください：

https://download.sedori-tool.com/files/sedori-tool-win

※ この URL は個人用です。他人と共有しないでください。
```

**方法 2: ダウンロード管理画面から取得**

以下の画面から取得することもできます：

```
https://account.sedori-tool.com/downloads
（ライセンスキーでログイン）

📥 sedori-tool-win.zip
   ↓ ダウンロードボタンをクリック
```

### 1-2. ファイルをダウンロード

メールの URL、または管理画面から **sedori-tool-win.zip** をダウンロード：

```
ダウンロード完了:
C:\Users\(ユーザー名)\Downloads\sedori-tool-win.zip
```

✅ ファイルが見えれば OK です。

## ❌ トラブルが出た場合

### エラー 1: 「Python が見つかりません」

**エラー画面の表示:**

```
================================================
  sedori-tool セットアップ開始
================================================

[error] Python 3.11 が見つかりません
[error] セットアップを中止しました

対応方法:
1. Python 3.11 をインストールしてください
2. インストール時に「Add Python to PATH」にチェックを入れる
3. セットアップを再実行してください

キーを押して終了...
```

**対応方法:**

1. [Python 3.11 公式サイト](https://www.python.org/downloads/) から Python をダウンロード
2. インストーラーを実行
3. **「Add Python to PATH」 にチェック** を入れる
4. インストール完了後、もう一度セットアップを実行

### エラー 2: 「アクセスが拒否されました」

**エラー画面の表示:**

```
================================================
  sedori-tool セットアップ開始
================================================

[error] アクセスが拒否されました: C:\Users\...
[error] ファイルの場所が制限されています

対応方法:
sedori-tool フォルダを Desktop に配置してください
```

**対応方法:**

1. **sedori-tool** フォルダを **C:\Users\(ユーザー名)\Downloads** から **C:\Users\(ユーザー名)\Desktop** に **移動**
2. Desktop に置き直してから、セットアップを再実行

> **📌 ポイント**: OneDrive や Documents では、セットアップがブロックされることがあります。必ず Desktop に置いてください。

### エラー 3: セットアップが途中で止まった

**対応方法:**

1. 黒い画面を閉じる（×ボタンまたは Alt+F4）
2. **0_初回セットアップ.bat** をもう一度 **ダブルクリック**
3. セットアップを再実行（中断したところから続行します）

```
================================================
  sedori-tool セットアップ開始
================================================

[info] 前回のセットアップから続行します
[info] 既にインストール済みのライブラリはスキップ...
...

✅ セットアップ完了！
```

### エラー 4: 「ライブラリのインストール失敗」

**エラー表示:**

```
[error] selenium のインストールに失敗しました
[error] ネットワーク接続を確認してください
```

**対応方法:**

1. インターネット接続を確認
2. セットアップを再実行

## 📋 ログファイルで詳細を確認

何か問題が発生した場合、ログファイルで詳細を確認できます：

```
C:\Users\(ユーザー名)\Desktop\sedori-tool\log\setup.log
```

**ログの開き方:**

1. sedori-tool フォルダを開く
2. **log** フォルダをダブルクリック
3. **setup.log** をテキストエディタで開く
4. エラーメッセージを確認

> **📞 サポート**: ログファイルの内容をコピーして、お問い合わせください。
