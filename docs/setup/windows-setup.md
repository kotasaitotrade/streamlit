# Windows での初回セットアップ

このページでは、Windows パソコンでせどりツールをセットアップする手順を **完全にガイド** します。

⏱️ **所要時間: 約 10 分**

---

## 📋 このページで行うこと

1. ✅ ダウンロード
2. ✅ 展開（解凍）
3. ✅ 初回セットアップの実行
4. ✅ セットアップ完了の確認

---

## ステップ 1: ダウンロード

### 1-1. Google Drive からダウンロード

以下のリンクを開いてください：

> **[sedori-tool-win.zip をダウンロード](https://drive.google.com/file/d/YOUR_FILE_ID/view?usp=sharing)**

または、以下の手順で検索してください：

1. Google Drive を開く
2. 検索ボックスに **「sedori-tool-win」** と入力
3. 検索結果から **sedori-tool-win.zip** をクリック
4. 右上の **⬇️ ダウンロード** ボタンをクリック

### 1-2. ダウンロード完了を確認

エクスプローラーを開いて、以下の場所を確認：

```
C:\Users\(ユーザー名)\Downloads\sedori-tool-win.zip
```

✅ ファイルが見えれば OK です。

---

## ステップ 2: 展開（解凍）

### 2-1. 右クリックメニューで展開

1. **sedori-tool-win.zip** を右クリック
2. **「すべて展開」** をクリック

**スクリーンショット:**
```
[右クリック]
├─ すべて展開 ← これをクリック
├─ 削除
└─ プロパティ
```

### 2-2. 展開先を指定

表示されたダイアログで：

1. 展開先を **C:\Users\(ユーザー名)\Desktop** に変更
2. **「展開」** ボタンをクリック

### 2-3. 展開完了を確認

デスクトップに **sedori-tool** フォルダが作成されれば OK です。

```
C:\Users\(ユーザー名)\Desktop\sedori-tool\
```

---

## ステップ 3: 初回セットアップの実行

### 3-1. セットアップファイルを開く

デスクトップの **sedori-tool** フォルダをダブルクリックして開きます。

以下のファイルが見えます：

```
📁 sedori-tool/
├─ 0_初回セットアップ.bat ← これをダブルクリック
├─ 1_設定画面を開く.bat
├─ 2_メルカリ新着.bat
├─ config/
└─ doc/
```

### 3-2. セットアップを実行

**0_初回セットアップ.bat** をダブルクリック

**黒い画面（コマンドプロンプト）が起動します。**

```
================================================
  必要環境のセットアップを開始します
================================================
[info] Python 3.11 確認...
[info] 必要ライブラリをインストール中...
...（インストール中）...
```

### 3-3. セットアップ完了を待つ

黒い画面に以下が表示されるまで待ってください：

```
================================================
✅ セットアップ完了！
次は「1_設定画面を開く.bat」を実行してください。
================================================
```

> ⚠️ **重要**: 黒い画面は自動的に閉じません。  
> 何か表示されたら、何かキーを押して閉じてください。

---

## ステップ 4: セットアップ完了の確認

### 4-1. ファイルが増えたか確認

セットアップ後、**sedori-tool** フォルダを開きます。

以下のフォルダが追加されていれば **セットアップ完了** です：

```
📁 sedori-tool/
├─ 0_初回セットアップ.bat
├─ 1_設定画面を開く.bat
├─ 📁 config/          ← ここに設定ファイルが追加される
├─ 📁 log/             ← ここにログが記録される
└─ 📁 src/             ← ツールのコードがここに展開される
```

### 4-2. 初回セットアップ再実行は不要

セットアップは 1 回だけで OK です。  
次は **ライセンス認証** に進みます。

## ❌ トラブルが出た場合

### 「Python が見つかりません」

**原因**: Python がインストールされていない

**対応方法**:

1. [Python 3.11 公式サイト](https://www.python.org/downloads/) から Python をダウンロード
2. インストーラーを実行
3. **「Add Python to PATH」 にチェック** を入れる
4. インストール完了後、セットアップを再実行

### 「アクセスが拒否されました」

**原因**: ファイルの場所が制限されている

**対応方法**:

1. **sedori-tool** フォルダを **C:\Users\(ユーザー名)\Desktop** に移動
2. **Documents** フォルダではなく **Desktop** に配置すること
3. 再度セットアップを実行

### セットアップが途中で止まった

**対応方法**:

1. 黒い画面を閉じる
2. **0_初回セットアップ.bat** をもう一度ダブルクリック
3. セットアップを再実行（中断したところから続行します）
