## 🛠️ エラーの詳細と対応方法

### セットアップ関連エラー

#### Python が見つかりません

**エラー画面:**

```
================================================
  sedori-tool セットアップ開始
================================================

[error] Python 3.10 が見つかりません
[error] セットアップを中止しました
```

**原因:**
- Python がインストールされていない
- Python が PATH に登録されていない

**対応方法:**

**Windows の場合:**

1. [Python 3.11 公式サイト](https://www.python.org/downloads/) を開く
2. Python インストーラーをダウンロード
3. インストーラーを実行

   ```
   セットアップウィザードが開く:
   
   ┌────────────────────────────────────┐
   │ Python Setup                       │
   ├────────────────────────────────────┤
   │ ☑️ Add Python 3.11 to PATH ←重要  │
   │    ここにチェックを入れる!         │
   │                                    │
   │        [Install Now]               │
   └────────────────────────────────────┘
   ```

4. 「Add Python to PATH」に **必ずチェック** を入れる
5. インストール完了後、セットアップを再度実行

**Mac の場合:**

```bash
# Homebrew で Python をインストール
brew install python@3.11

# インストール確認
python3 --version
```

#### Permission denied

**エラー画面（Mac）:**

```
$ ./0_初回セットアップ.sh
zsh: permission denied: ./0_初回セットアップ.sh
```

**原因:**
- スクリプトに実行権限がない

**対応方法:**

```bash
cd ~/Desktop/sedori-tool-mac
chmod +x *.sh
./0_初回セットアップ.sh
```

**Windows の場合は以下を実行:**

```
コマンドプロンプト（管理者）を起動してから：
icacls "C:\Users\(ユーザー名)\Desktop\sedori-tool" /grant:r "%username%":F /T
```

#### アクセスが拒否されました

**エラー画面:**

```
================================================
[error] アクセスが拒否されました
[error] ファイルの場所が制限されています
================================================
```

**原因:**
- OneDrive や Documents など、保護されたフォルダに配置している
- フォルダ権限が制限されている

**対応方法:**

sedori-tool フォルダを **Desktop** に移動してください：

**Windows の場合:**

```
1. Desktop を開く
2. sedori-tool フォルダをドラッグして移動
   → Desktop に配置

正しい位置:
C:\Users\(ユーザー名)\Desktop\sedori-tool
```

**Mac の場合:**

```bash
cd ~/Desktop
mv ~/Downloads/sedori-tool-mac ~/Desktop/
```

その後、セットアップを再度実行してください。

#### ライブラリのインストール失敗

**エラー画面:**

```
[error] selenium のインストールに失敗しました
[error] ネットワーク接続を確認してください
```

**原因:**
- インターネット接続が不安定
- pip サーバーがダウンしている

**対応方法:**

1. インターネット接続を確認
2. WiFi を再接続する
3. セットアップを再度実行

```bash
# Windows の場合
0_初回セットアップ.bat をダブルクリック

# Mac の場合
./0_初回セットアップ.sh
```

### ライセンス認証エラー

#### ライセンスキーが無効です

**エラー画面:**

```
❌ 認証に失敗しました

エラー: ライセンスキーが無効です
```

**原因:**
- キーの形式が違っている
- キーの前後に空白がある
- キーがコピーできていない

**対応方法:**

1. メールを開き直す
2. ライセンスキーをもう一度選択してコピー

   ```
   例: SEDORI-XXXX-YYYY-ZZZZ
   
   ★ 前後に空白がないか確認！
   ```

3. 設定画面の入力欄に貼り付け
4. 「認証を実行」をクリック

---

#### ネットワーク接続エラー

**エラー画面:**

```
❌ 認証に失敗しました

エラー: ネットワーク接続エラー
インターネット接続を確認してください。
```

**原因:**
- インターネット接続がない
- ファイアウォール設定がブロックしている

**対応方法:**

1. インターネット接続を確認
2. WiFi を再接続する
3. ファイアウォール（Windows Defender など）を確認
4. もう一度「認証を実行」をクリック

### 監視・値下げエラー

#### 新着商品が検出されない

**症状:**
- メルカリ/ヤフフリを監視しても、新着商品が検出されない
- Discord に通知が来ない

**原因:**
- キーワードが不適切（見つからない商品名）
- 価格帯が合致していない
- 商品状態フィルターが厳しすぎる

**対応方法:**

1. キーワードを短くする

   ```
   変更前: iPhone SE 第3世代 未使用
   変更後: iPhone  or  iPhone SE
   ```

2. 価格帯を広げる

   ```
   変更前: 5,000 ～ 8,000 円
   変更後: 3,000 ～ 15,000 円
   ```

3. 商品状態フィルターをすべてチェック

   ```
   ☑️ 未使用に近い
   ☑️ 目立った傷や汚れなし
   ☑️ やや傷や汚れあり
   ```

4. テストボタンをクリックして確認

---

#### 値下げが実行されない

**症状:**
- 値下げ設定をしたのに実行されない
- Discord に通知が来ない

**原因:**
- 値下げ対象の商品がない
- ユーザー ID が違っている
- メルカリ/ヤフオク のセッションが切れている

**対応方法:**

1. メルカリ/ヤフオク にログインしているか確認
2. 出品中の商品があるか確認
3. ユーザー ID を確認

   ```
   メルカリ: マイページ で確認
   ヤフオク: Yahoo Japan ID で確認
   ```

4. ログファイルで詳細を確認

   ```
   Windows:
   C:\Users\(ユーザー名)\Desktop\sedori-tool\log\

   Mac:
   ~/Desktop/sedori-tool-mac/log/
   ```

---

#### Discord に通知が来ない

**症状:**
- 新着商品が検出されているのに Discord に通知が来ない
- テスト通知も来ない

**原因:**
- Webhook URL が無効
- Webhook が削除されている
- Discord サーバーに接続できない

**対応方法:**

1. Webhook URL を確認

   ```
   設定画面 → Discord設定
   Webhook URL を確認
   ```

2. Webhook URL が削除されていないか確認

   Discord サーバーで：
   ```
   # general を右クリック
   → Webhook を確認
   → 古い Webhook を削除
   ```

3. 新しい Webhook URL を作成

   ```
   Discord サーバー
   # general 右クリック
   → Webhook → 新規作成
   → URL をコピー
   ```

4. 設定画面に新しい URL を貼り付けて保存

5. テスト実行で確認

### 自動実行エラー

#### タスクが実行されない（Windows）

**症状:**
- 指定時刻になってもツールが実行されない
- ログが生成されない

**原因:**
- タスクスケジューラに登録されていない
- プログラムのパスが間違っている
- Windows Defender がブロックしている

**対応方法:**

1. タスクスケジューラで登録を確認

   ```
   Windows キー + R
   taskschd.msc を入力
   
   左のツリー:
   タスク スケジューラー ライブラリ
   → sedori-tool-autoschedule が表示されているか
   ```

2. 登録されていない場合は再度作成

   詳細: [Windows タスクスケジューラの設定](../automation/windows-scheduler.md)

3. プログラムのパスを確認

   ```
   タスク編集 → 操作タブ
   
   正しい例:
   C:\Users\yamada\Desktop\sedori-tool\4_メルカリ値下げ.bat
   ```

4. Windows Defender で除外設定

   ```
   Windows セキュリティ
   → ウイルスと脅威の防止
   → 除外の管理
   → sedori-tool フォルダを追加
   ```

---

#### launchd が動作しない（Mac）

**症状:**
- 指定時刻になってもツールが実行されない
- ログが生成されない

**原因:**
- launchd に登録されていない
- plist ファイルが破損している
- Mac がスリープ状態

**対応方法:**

1. launchd に登録されているか確認

   ```bash
   launchctl list | grep sedori
   ```

2. 登録されていない場合は再度登録

   ```bash
   cd ~/Desktop/sedori-tool-mac/bin
   ./setup_autoschedule.sh
   ```

3. Mac がスリープ状態になっていないか確認

   ```
   システム環境設定
   → 省エネルギー
   → 「コンピュータをスリープさせない」に設定
   ```

4. ログを確認

   ```bash
   cat ~/Desktop/sedori-tool-mac/log/autoschedule.log
   ```

## 📋 ログファイルで詳細を確認

エラーメッセージが不明確な場合、ログファイルで詳細を確認できます。

**ログの場所:**

**Windows:**
```
C:\Users\(ユーザー名)\Desktop\sedori-tool\log\
```

**Mac:**
```
~/Desktop/sedori-tool-mac/log/
```

**ログを開く（Windows）:**

1. エクスプローラーで上記のフォルダを開く
2. ログファイル（`*.log`）をテキストエディタで開く
3. エラーメッセージを検索

**ログを確認（Mac）:**

```bash
cat ~/Desktop/sedori-tool-mac/log/*.log
```

**ログの見方:**

```
[2026-06-06 09:00:15] [INFO] セットアップ開始
[2026-06-06 09:00:16] [SUCCESS] Python 確認完了
[2026-06-06 09:00:17] [ERROR] ライブラリのインストール失敗
[2026-06-06 09:00:18] [ERROR] 原因: ネットワークエラー
[2026-06-06 09:00:19] [INFO] セットアップを再実行してください
```

- **[INFO]**: 通常の実行情報
- **[SUCCESS]**: 成功した処理
- **[ERROR]**: エラーが発生した処理
- **[WARNING]**: 注意（処理は続行）
