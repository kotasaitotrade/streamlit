## 🎯 このツールでできること

### 📊 新着監視機能
- メルカリ・ヤフフリの新着商品をリアルタイムで通知
- 価格・条件で自動フィルタリング
- Discord で即座に確認

### 📉 自動値下げ機能
- 設定した商品を自動で値下げ
- 時間帯・間隔を自由に設定
- 値下げ結果を Discord で報告

### 🔄 完全自動化
- 30分ごとに自動実行
- 寝ている間も動作
- エラーも自動で検知
