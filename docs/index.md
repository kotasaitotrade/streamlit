# 🎯 せどりツール マニュアル

**メルカリ・ヤフフリの新着監視・自動値下げをすべて自動化するための完全ガイド**

このマニュアルは、せどりツールを **ゼロから完全自動化** するための完全ガイドです。  
**詳細な図解付き** で、パソコンに詳しくない方でも安心して進められます。

### 📊 新着監視機能

```
【メルカリ・ヤフフリの新着商品を自動監視】

    └─ 夜中や忙しいときも自動で監視

2️⃣  条件に合った商品を自動フィルタ
    ├─ 価格: 5,000〜10,000 円
    ├─ 状態: 未使用に近い
    └─ 配送: 送料込み

3️⃣  Discord で即座に通知
    ├─ スマートフォンにプッシュ通知
    ├─ 商品リンク・画像・価格をまとめて表示
    └─ 外出先でもすぐに確認

    └─ 新着商品をいち早くゲット！
```

### 📉 自動値下げ機能

```
【自分の商品を自動で値下げして売上最大化】

1️⃣  設定した商品を自動監視
    └─ 「売れない商品」を自動検知

2️⃣  自動で段階的に値下げ
    ├─ 1日目: 現在価格 - 500円
    ├─ 2日目: 現在価格 - 1000円
    ├─ 3日目: 現在価格 - 1500円
    └─ 設定は自由にカスタマイズ可能

3️⃣  値下げ結果を Discord で報告
    ├─ 何円値下げしたか
    ├─ 新しい価格は？
    └─ すべて自動で通知

4️⃣  手動での値下げ作業が不要
    └─ 時間を有効活用できる！
```

## ✅ よくある質問（FAQ）

### Q: セットアップにはどのくらい時間がかかりますか？

**A:** 合計で約 60 分です。
- セットアップ（初回のみ）: 10-15 分
- 認証・設定: 30-40 分
- 自動実行設定: 10 分

### Q: 途中で中止することはできますか？

**A:** はい、いつでも中止できます。次回から途中から再開できます。

### Q: 複数のパソコンで使えますか？

**A:** はい、複数のパソコンで使用できます。ライセンスキーがあればすぐに始められます。

### Q: エラーが出ました。どうしたらいいですか？

**A:** 各ページの「❌ トラブルが出た場合」を確認するか、[よくあるエラー](./troubleshoot/faq.md) をご覧ください。
