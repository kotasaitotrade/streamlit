# ヤフフリ新着監視の設定

**ヤフオク・ラクマの新着商品をリアルタイムで監視して、条件に合った商品を Discord で通知します。**

⏱️ **所要時間: 約 15 分**

---

## 設定方法

メルカリ監視と同様の手順で設定します。

### 1. ヤフフリ監視タブを選択

設定画面で **「ヤフフリ監視」** タブをクリック

### 2. キーワードを設定

```
iPhone
iPad
MacBook
Apple Watch
AirPods
```

### 3. 価格・条件を設定

```
最小価格: 3,000 円
最大価格: 50,000 円
```

### 4. 「保存」をクリック

---

## 設定例

### ラクマ向け設定

```
キーワード: iPhone, iPad

価格帯: 2,000 ～ 20,000 円

新着の時間: 過去 24 時間
```

### ヤフオク向け設定

```
キーワード: Apple製品

価格帯: 3,000 ～ 80,000 円

入札状況: 入札なし（穴場商品を探す）
```
