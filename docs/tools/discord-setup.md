# Discord 通知の設定

**ツールの実行結果（新着商品・値下げ通知など）をスマートフォンの Discord で受け取るようにします。**

⏱️ **所要時間: 約 10 分**

---

## 📋 このページで行うこと

1. ✅ Discord サーバーを作成（または既存を使用）
2. ✅ Webhook URL を取得
3. ✅ ツールに Webhook URL を設定
4. ✅ テスト通知を送信して動作確認

---

## ステップ 1: Discord サーバーを作成

### 1-1. Discord をダウンロード・インストール

1. [Discord 公式サイト](https://discord.com/download) から Discord をダウンロード
2. アカウントを作成（メールアドレスとパスワード）
3. インストール完了後、Discord を開く

> **💡 ポイント**: スマートフォン版アプリをインストールすれば、外出先からでも通知が受け取れます。

## ステップ 2: Webhook URL を取得

### 2-1. チャンネル設定を開く

サーバーが作成されたら、**# general** チャンネルを右クリック：

```
左のサイドバー:
┌─────────────────────────┐
│ 📘 sedori-tool 通知      │
│                         │
│ チャンネル:              │
│ ├─ # general ← 右クリック│
│ └─ # 告知              │
└─────────────────────────┘

右クリックメニュー:
┌────────────────────────────┐
│ ✏️ チャンネルを編集        │
│ 📍 チャンネルトピック     │
│ 🔔 通知設定              │
│ ━━━━━━━━━━━━━━━━━━━  │
│ ✂️ チャンネルを削除       │
│ ⚙️ インテグレーション     │
│ 🔗 Webhook ← ここ!       │
│                          │
└────────────────────────────┘
```

### 2-2. Webhook を作成

右クリックメニューから **「Webhook」** をクリック：

**Webhook 設定画面:**

```
┌────────────────────────────────────────┐
│ # general - Webhook                    │
├────────────────────────────────────────┤
│                                        │
│ Webhook を新規作成:                    │

│ ┌─────────────────────────────────┐   │
│ │ sedori-tool-notifier            │   │
│ └─────────────────────────────────┘   │
│                                        │
│ Webhook アイコン:                      │
│ [📋 アイコンを選択]                    │
│                                        │
│           [Webhook を作成]             │
│                                        │
└────────────────────────────────────────┘
```

**設定:**
1. Webhook 名: **sedori-tool-notifier**
2. **「Webhook を作成」** をクリック

### 2-3. Webhook URL をコピー

Webhook が作成されると、URL が表示されます。

**Webhook 作成後の画面:**

```
┌────────────────────────────────────────┐
│ # general - Webhook                    │
├────────────────────────────────────────┤
│                                        │
│ ✅ Webhook を作成しました！            │
│                                        │
│ Webhook 名: sedori-tool-notifier      │
│                                        │
│ Webhook URL:                           │
│ ┌──────────────────────────────────┐  │
│ │ https://discord.com/api/webhooks │  │
│ │ /1234567890/abcdefgh...          │  │
│ │ ijklmnopqrstuvwxyz (長いURLです) │  │
│ └──────────────────────────────────┘  │
│              [コピー]                   │
│              [削除]                     │
│                                        │
└────────────────────────────────────────┘
```

**URL をコピー:**
1. URL の入力欄をクリック
2. **「コピー」** ボタンをクリック

> **⚠️ 重要**: この URL は secret です。他人に教えないでください！

## ❌ 通知が来ない場合

### トラブル 1: テスト通知が届かない

**原因と対応:**

1. **Webhook URL が間違っている**
   - URL をコピーし直す
   - 設定画面で再度貼り付け

2. **Discord サーバーがダウンしている**
   - Discord の状態ページを確認: https://status.discord.com

3. **ネットワーク接続エラー**
   - インターネット接続を確認
   - WiFi を再接続

### トラブル 2: 「Webhook が無効です」エラー

**エラー表示:**

```
❌ Webhook が無効です

原因:
1. Webhook URL が削除されている
2. Webhook URL が間違っている

対応方法:
1. Discord で新しい Webhook URL を作成
2. 設定画面に貼り付け
```

**対応方法:**

1. Discord サーバーを開く
2. **# general** を右クリック
3. **「Webhook」** → **「新規作成」**
4. 新しい Webhook URL をコピー
5. 設定画面に貼り付け

### トラブル 3: 「Webhook URL の形式が違います」

**エラー表示:**

```
❌ Webhook URL の形式が違います

Webhook URL の例:
https://discord.com/api/webhooks/
1234567890/abcdefghijklmnopqr...
```

**原因:**
- URL がコピーされていない
- URL に余分な文字が付いている

**対応方法:**

1. Discord の Webhook 設定画面に戻る
2. URL を選択してコピーし直す
3. 設定画面に貼り付け
