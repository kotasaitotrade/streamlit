# メルカリ新着監視の設定

**メルカリの新着商品をリアルタイムで監視して、条件に合った商品を Discord で通知します。**

⏱️ **所要時間: 約 15 分**

---

## 📋 このページで行うこと

1. ✅ メルカリのキーワードを設定
2. ✅ 価格帯を設定
3. ✅ 商品状態を設定
4. ✅ 設定を保存して動作確認

---

## ⚠️ 注意

このツールは **メルカリの利用規約に準拠** しています。
ただし、Mercari API の利用制限に注意してください。

---

## ステップ 1: 監視キーワードを設定

### 1-1. 設定画面を開く

デスクトップの **sedori-tool** フォルダから、**1_設定画面を開く.bat** をダブルクリック。

### 1-2. メルカリ監視タブを選択

設定画面で **「メルカリ監視」** タブをクリック：

```
┌──────────────────────────────────────┐
│ sedori-tool 設定画面                 │
├──────────────────────────────────────┤
│ タブ: ライセンス │ Discord │        │
│      🔍 メルカリ監視 │ ...           │
│                                      │
│ メルカリ監視設定パネル:              │
│ ┌──────────────────────────────────┐│
│ │ 📊 メルカリ新着監視              ││
│ │                                  ││
│ │ 監視キーワード:                  ││
│ │ ┌────────────────────────────┐   ││
│ │ │ （例）iPhone SE             │   ││
│ │ │       MacBook Air           │   ││
│ │ │       iPad                  │   ││
│ │ └────────────────────────────┘   ││
│ │                                  ││
│ │         [保存]      [テスト]      ││
│ │                                  ││
│ └──────────────────────────────────┘│
│                                      │
└──────────────────────────────────────┘
```

### 1-3. キーワードを入力

監視したい商品キーワードを入力します。1行に1つのキーワード：

```
iPhone SE
MacBook Air
iPad Pro
AirPods
```

> **💡 ポイント**: より詳しいキーワードを入力すると、不要な検索結果が減ります。

### 1-4. 条件を設定

**価格帯:**
```
最小価格: 5000
最大価格: 50000
```

**商品状態:**
```
✅ 未使用に近い
✅ 目立った傷や汚れなし
☑️ やや傷や汚れあり
```

**配送方法:**
```
✅ 送料込み（出品者負担）
☑️ 送料別（購入者負担）
```

## 📋 設定例

### 初心者向け設定

```
キーワード:
iPhone
iPad
MacBook

価格帯: 5,000 ～ 30,000 円

状態: 未使用に近い、目立った傷や汚れなし
```

### 本格的な設定

```
キーワード:
iPhone SE (第3世代)
iPhone 13
iPhone 12 Pro
MacBook Air M1
MacBook Pro 14インチ

価格帯: 5,000 ～ 80,000 円

状態: すべてチェック（条件を広げる）
```

---

## ❌ 監視が動作しない場合

### トラブル 1: キーワードが設定されていない

**対応方法:**
1. メルカリ監視タブを確認
2. キーワードを入力
3. 「保存」をクリック

### トラブル 2: 検出結果が少ない

**対応方法:**
1. キーワードを短くする（例: `iPhone SE` → `iPhone`）
2. 価格帯を広げる
3. 商品状態をすべてチェック
