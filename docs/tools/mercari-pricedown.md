# メルカリ自動値下げの設定

**自分が出品したメルカリの商品を自動で値下げして、売上を最大化します。**

⏱️ **所要時間: 約 15 分**

---

## 📋 このページで行うこと

1. ✅ メルカリ ID を設定
2. ✅ 値下げルールを設定
3. ✅ 値下げ対象の商品を選択
4. ✅ 設定を保存して動作確認

---

## ⚠️ 重要な注意事項

このツールはメルカリの規約に準拠して動作します。  
ただし、過度な値下げや自動化の悪用はメルカリの利用規約違反となる場合があります。

---

## ステップ 1: メルカリ ID を設定

### 1-1. 設定画面を開く

**1_設定画面を開く.bat** をダブルクリック

### 1-2. メルカリ値下げタブを選択

「メルカリ値下げ」タブをクリック

### 1-3. メルカリ ID を入力

メルカリ ID（またはユーザーネーム）を入力：

```
例: mercari_user_12345
```

> **💡 ポイント**: メルカリ ID は [マイページ](https://www.mercari.com/mypage) で確認できます。

---

## ステップ 2: 値下げルールを設定

値下げするタイミングと金額を設定：

```
1日目: 現在価格 - 500円
2日目: 現在価格 - 1,000円
3日目: 現在価格 - 1,500円
5日目: 現在価格 - 2,000円

最小価格: 2,000円（これ以下には値下げしない）
```

---

## ステップ 3: 値下げ対象の商品を選択

```
☑️ 出品中の商品すべて
☑️ 閲覧数が 10 以下の商品
☑️ 2日以上売れていない商品
☐ 特定のカテゴリのみ
```

---

## ステップ 4: 設定を保存

「保存」をクリック

```
✅ メルカリ値下げ設定を保存しました！
```

---

## 📊 値下げ結果の確認

Discord に以下のような通知が送信されます：

```
📉 メルカリ値下げ完了

iPhone SE 第3世代
定価: ¥9,999 → 新価格: ¥9,499
-¥500 値下げ
🔗 https://mercari.com/items/...

このように 5 商品を値下げしました。
```
