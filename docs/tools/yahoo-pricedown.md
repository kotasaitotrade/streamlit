# ヤフオク・ラクマ自動値下げの設定

**ヤフオク・ラクマの出品商品を自動で値下げします。**

⏱️ **所要時間: 約 15 分**

---

## 設定方法

メルカリ値下げと同様の手順で設定します。

### 1. ヤフフリ値下げタブを選択

設定画面で **「ヤフフリ値下げ」** タブをクリック

### 2. ユーザー ID を設定

```
ヤフオク ID: (Yahoo Japan ID)
ラクマ ID: (Rakuten ID)
```

### 3. 値下げルールを設定

```
1日目: -500円
2日目: -1000円
3日目: -1500円

最小価格: 2000円
```

### 4. 「保存」をクリック

---

## 設定例

### ヤフオク向け

```
値下げ対象: 残り期間が 3 日以下
値下げ金額: 500 ～ 2000 円
```

### ラクマ向け

```
値下げ対象: 出品から 48 時間以上
値下げ金額: 300 ～ 1500 円
```
