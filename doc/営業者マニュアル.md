## 1. ログイン方法

1. ブラウザでツウチマネージャーのURLにアクセスします
2. **「ログイン」タブ**が表示されていることを確認します
3. 「ID / 名前」欄に、管理者から通知されたログインIDを入力します
4. 「パスワード」欄に初期パスワードを入力し、**「ログイン」**ボタンを押します

> **初回ログイン時の注意:**  
> 管理者が「次回ログイン時にパスワード変更を要求する」を設定した場合、ログイン直後に  
> **「パスワードの変更が必要です」** という画面が表示されます。  
> 画面の指示に従い、新しいパスワード（6文字以上）を設定してください。  
> 設定後は自動的にメイン画面に移動します。

## 2. 画面の見方

ログイン後、左側に**サイドバー**が表示されます。

```
[あなたの名前]
🟡 営業者
─────────────
メニュー
○ 通知設定
○ プラン契約・解約
○ アカウント設定
● 担当ユーザー     ← 営業者専用メニュー
○ 月額料金参照     ← 営業者専用メニュー
─────────────
[ログアウト]
```

営業者アカウントでは **「担当ユーザー」** と **「月額料金参照」** が表示されます。  
（「ユーザー管理」「パスワード管理」は管理者のみ）

## 3. 担当ユーザー一覧の使い方

### 画面の開き方

サイドバーの **「担当ユーザー」** をクリックします。

### 表示内容

管理者から担当者として割り当てられたユーザーの一覧が表示されます。

| 列名 | 内容 |
|------|------|
| ユーザー名 | 担当ユーザーの名前 |
| ユーザーID | DiscordのユーザーID |
| プラン | 契約中のプラン（例: フル ¥9,000） |
| 入会日 | 初回決済完了日（= 毎月の支払日） |
| 当月支払日 | 今月のあなたへの支払日 |
| 翌月支払予定日 | 来月のあなたへの支払予定日 |
| ステータス | **継続中** / **退会済** / **⚫ 無効** |
| 今月入金額 | あなたへの支払い額 |

**入金確認チェックの使い方:**
- 管理者からの月次振込を確認したら、表の上にある **「📥 N月分の入金を確認しました」** チェックボックスに1度だけチェックを入れてください
- このチェックは月に1回でOKです（ユーザーごとに付ける必要はありません）
- 管理者と共有のステータスで、即座に反映されます
- **過去月のチェックも可能**：月額料金参照ページで対象月を選び、画面下部のチェックボックスで過去月も確認/解除できます

> **黄色い行**は「退会済」または「無効」ユーザーです

> この画面は参照のみです。情報の変更は管理者（齋藤）が行います。

## 4. 月額料金参照の使い方

### 画面の開き方

サイドバーの **「月額料金参照」** をクリックします。

### 対象月の選択

画面上部に **「年」「月」** の入力欄があります。  
確認したい年月を入力してください（デフォルトは当月）。

```
年: [2026] −  ＋      月: [6] −  ＋
```

### 表示内容

| 列名 | 内容 |
|------|------|
| ユーザー名 | 担当した入会者の名前 |
| プラン名 | 契約中のプラン（例: フル ¥9,000） |
| 月額料金 | そのユーザーが支払う月額金額 |
| 入会日 | 初回決済完了日 |
| 退会日 | 解約期間終了日（継続中の場合は「継続中」） |
| ステータス | **継続中** / **退会済** |
| 営業者取り分 | その月にあなたに支払われる金額 |

> **黄色い行**は「退会済」ユーザーです（その月に在籍していたため集計対象）

### サマリー（画面下部）

```
対象ユーザー数     月額合計（売上）     6月分 支払い予定
     2人              ¥16,000              ¥7,000
```

- **対象ユーザー数**: 当月アクティブだった自分の担当ユーザー数
- **月額合計（売上）**: ユーザーが支払った金額の合計（参考値）
- **X月分 支払い予定**: あなたへの支払い予定合計額

## 5. 支払い計算の仕組み

### 計算ルール

支払いはベースプラン金額の **50%** です。オプション（+¥2,000）は含みません。

| ユーザーのプラン | 月額料金 | あなたへの支払い |
|---|---|---|
| フルプラン | ¥9,000 | **¥4,500** |
| フルプラン + オプション | ¥11,000 | **¥4,500**（オプション分除く） |
| ライトプラン | ¥5,000 | **¥2,500** |
| ライトプラン + オプション | ¥7,000 | **¥2,500**（オプション分除く） |

### 支払い対象の条件

**月末締め**で集計します。以下の条件を全て満たすユーザーが対象です：

1. あなたが担当者として登録されている
2. 対象月の月末までに入会済み
3. 対象月の初日以降に在籍していた（退会日が対象月初日以降）

**例:**
- 6月15日入会 → 6月分から対象
- 5月20日に「6月30日付け解約」→ 6月分は対象、7月分から対象外
- 4月入会・継続中 → 毎月対象

### 月次支払いの流れ

```
月末
 ↓
管理者が「月額料金参照」で各営業者の支払い金額を確認
 ↓
月次で各営業者に支払い
```

## 6. パスワードの変更方法

### 自分でパスワードを変更する場合

1. サイドバーの **「アカウント設定」** をクリック
2. 「現在のパスワード」を入力
3. 「新しいパスワード」を入力（6文字以上）
4. 「確認（再入力）」に同じパスワードを入力
5. **「パスワードを変更する」** ボタンを押す

### 管理者がパスワードを変更した場合

管理者があなたのパスワードを変更した際、「次回ログイン時に変更要求」が設定されている場合があります。  
その場合、次のログイン時に自動的に変更画面が表示されます。

## 7. よくある質問

**Q: 自分が担当していないユーザーの情報は見られますか？**  
A: いいえ。営業者は自分が担当として割り当てられたユーザーの情報のみ表示されます。

**Q: 担当ユーザーへの割り当ては自分でできますか？**  
A: いいえ。担当ユーザーの割り当ては管理者（齋藤）が行います。担当ユーザーが表示されない場合は管理者にご連絡ください。

**Q: 月の途中で入会したユーザーはその月から集計されますか？**  
A: はい。入会日が対象月内であれば、その月から集計対象になります。

**Q: ログインIDを忘れた場合は？**  
A: 管理者（齋藤）にご連絡ください。

**Q: 「通知設定」「プラン契約・解約」も使えますか？**  
A: 表示はされますが、通知設定の利用にはプラン契約が必要です。営業者アカウントはサービスのモニタリング用途には契約不要の機能（月額料金参照）のみご利用ください。
